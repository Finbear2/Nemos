# Nemos

Nemos is a lightweight static nomad net site generator using a memos server for a post-based blogging system. It runs as a simple python script in the pages folder of your nomad network directory and can be run as a cron job or manually. **Requires a memos server**

## Features

- Customisable markdown to micron converter
- Simple setup with no API key
- Templates system for full customizability
